# 관절 토크 좌표계 검토

최종 모델의 저장된 Request 결과를 다시 읽고, 회전 조인트의 로컬 회전축에 맞추어 토크를 재계산했다. 동역학 솔버를 새로 실행하거나 모델의 모션을 변경한 작업은 아니다.

## 성분 선택의 근거

설치된 RecurDyn 2023 공식 도움말의 revolute joint 설명은 회전축을 마커의 Z축으로 정의한다. Request 설명은 결과를 reference marker 좌표계에 투영한다고 설명한다. 확인한 도움말 소스는 `Professional/Professional_ch02_s02_06.rst.txt`와 `Subentity/Subentity_ch09_s00_index.rst.txt`이다.

최종 RMD의 Request 1–6은 해당 회전 조인트와 같은 I/J 마커 쌍을 사용하며, RM은 각 조인트의 J 마커다. 따라서 이 파일에서 읽을 회전축 성분은 모든 관절에서 TZ이다. 후처리 스크립트는 조인트 종류, 이름, I/J/RM 연결, 단위 및 원시 Request 헤더를 검사하고 이 조건이 다르면 중단한다.

| 관절 | I 마커 | J 및 RM 마커 | 수정 전 성분 | 올바른 회전축 성분 |
|---|---:|---:|---|---|
| J1 | 190 | 197 | TZ | TZ |
| J2 | 186 | 192 | TY | TZ |
| J3 | 182 | 188 | TY | TZ |
| J4 | 178 | 184 | TY | TZ |
| J5 | 174 | 180 | TZ | TZ |
| J6 | 138 | 176 | TY | TZ |

## 계산 방법

각 관절의 저장 시각별 모멘트 TZ를 1000으로 나누어 N·mm에서 N·m로 변환했다. 그 절댓값의 최댓값을 관절의 샘플 최대 토크로 사용했다. 여유를 둔 관절 토크는 이 최댓값의 1.5배다.

| 관절 | 기존 최대 토크 (N·m) | 수정 최대 토크 (N·m) | 수정값 × 1.5 (N·m) |
|---|---:|---:|---:|
| J1 | 6.461 | 6.461 | 9.691 |
| J2 | 6.093 | 54.079 | 81.119 |
| J3 | 13.791 | 21.968 | 32.953 |
| J4 | 12.114 | 15.211 | 22.817 |
| J5 | 6.642 | 6.642 | 9.963 |
| J6 | 4.832 | 0.120 | 0.180 |

기존 J2/J3/J4/J6의 TY는 이 Request 좌표계에서 회전축 토크가 아닌 모멘트 성분이다. 원본 CSV는 이력을 확인할 수 있도록 `data/original/`에 보관한다.

## 재현 및 해석 범위

```bash
python3 scripts/postprocess_results.py
python3 scripts/postprocess_results.py --check
```

첫 명령은 `results/`에 CSV와 검증 JSON을 생성한다. 두 번째 명령은 파일을 바꾸지 않고 저장 결과가 재계산과 일치하는지 확인한다. Python 3.10 이상이며 추가 패키지는 필요 없다.

결과는 0–18.5 s의 901개 저장 시각을 기준으로 한다. 저장 시각 사이에서 더 큰 최대값이 발생할 가능성은 별도 검토가 필요하다. 이 값은 조인트 출력축의 하중 기준이며 모터 축 토크와 같다고 가정하지 않는다. 실제 모터 선정에는 감속비, 효율, 속도별 토크 곡선, RMS 토크와 운전 주기가 필요하다.

CSV의 웨이포인트 구간 평균 속도는 순간 최대 속도가 아니다. 이전 보고서의 서로 다른 최대 토크와 평균 속도를 곱한 전력 추정치를 실제 순간 최대 전력으로 재사용하지 않는다. 이번 수정 결과에는 그 전력 추정치를 포함하지 않았다.
