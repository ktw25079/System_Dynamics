# 기존 산출물 정정 내역

이 저장소는 2026년 1학기 과제의 최종 모델을 보존하면서, 2026-09-17 GitHub 정리 과정에서 확인한 설명과 후처리 오류를 구분합니다. 원본 모델의 모션은 변경하지 않았습니다.

## 토크 좌표축

기존 후처리는 J1/J5에 TZ, J2/J3/J4/J6에 TY를 사용했습니다. 그러나 최종 RMD의 Request가 각 조인트의 기준 마커를 reference marker로 사용하므로 회전축 성분은 모두 TZ입니다. 수정한 결과는 `results/`에, 이전 CSV는 `data/original/`에 보관했습니다. 이전 보고서의 모터 용량 표는 현재 권장값으로 사용하지 않습니다. [검토 근거](torque_review.md)를 참고하세요.

## 접촉과 베어링 하강

최종 모델에는 contact force entity가 없습니다. 단일 강체 그리퍼와 OnOff hold/grip/guide 구속, 수직 guide motion으로 물체를 이송·정착합니다. 이전 문서의 contact 유지, 자유낙하, 접촉으로 정착했다는 표현은 최종 구현과 다릅니다. 현재 모델에 대한 설명은 [모델 구성](model.md)을 따릅니다.

## 검증 표의 의미

기존 clearance audit의 PASS는 지정된 형상·목표 좌표에 대한 계산 결과입니다. 전 경로 충돌 검사, 접촉력 검증, 실제 로봇 안전성 검증을 뜻하지 않습니다. 이번 정리에서도 솔버를 새로 실행하지 않았으므로 ‘새로운 재해석 성공’으로 표시하지 않습니다.

## 보관 보고서

`reports/original/`은 기존 수업 제출용 폴더에 있던 보고서의 보관본이며, 현재 저장소 설명을 반영해 다시 편집한 보고서가 아닙니다. 베어링 도식의 `OD = 64 mm` 표기는 잘못되었으며 모델의 외경은 84 mm, 내경은 64 mm입니다. 최종 모델의 재현 절차와 수정 결과는 이 저장소의 README, `docs/`, `results/`를 우선합니다.
