# 과제 요구사항과 구현

UR3로 두 물체를 이송하고 관절 토크를 분석하는 시스템동역학 과제입니다. 아래 조건은 `SysDyn_RD_Project.pdf` 1쪽을 기준으로 정리했습니다.

## 필수 요구사항과 프로젝트 구성

| 필수 요구사항 | 프로젝트에서의 대응 | 확인할 자료 |
| --- | --- | --- |
| 제공된 `UR3.step`을 사용하여 RecurDyn에서 동역학 모델 구성 | UR3 링크와 6개 revolute joint를 연결한 다물체 모델 | RecurDyn 모델, RMD 텍스트 모델, 조인트 표 |
| 두 개 이상의 물체를 원하는 위치로 이동 | 스크류와 베어링을 순차적으로 이송하는 작업 | 작업 순서 설명, 시뮬레이션 모델 |
| 물체마다 시작점과 끝점을 포함하여 최소 3개 waypoint 사용 | 스크류 5개, 베어링 5개의 핵심 waypoint를 저장 | waypoint CSV와 RPP |
| 각 조인트의 액추에이터 토크를 확인하고 필요한 모터 용량 판단 | J1–J6 토크 결과를 저장하고 최대 절댓값 토크에 안전율 1.5 적용 | 토크 시계열, 모터 용량 요약 CSV |
| CAD 파일과 보고서 내용으로 결과를 재현할 수 있게 설명 | 링크·조인트·모션·구속·해석 설정과 실행 순서 정리 | 모델 설명, 원본 보유 시 실행 안내, 정정 내역 |

안전율 **1.5**와 물체별 **5개 waypoint**를 적용했습니다. 최종 모델은 STEP 모션과 강체 그리퍼의 구속 전환을 사용하며, 베어링 정렬·삽입을 작업 경로에 포함했습니다.

최대 토크는 지정 경로의 조인트 하중이며, 모터 선정에는 감속비·효율·속도·RMS 토크를 추가로 검토해야 합니다. [토크 계산](torque_review.md) · [모델링 범위](model.md) · [실행 방법](reproduction.md)
